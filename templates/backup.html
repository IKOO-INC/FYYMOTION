2) UPLOAD / RESTORE BACKUP (menimpa data sekarang)
PERINGATAN: Restore akan MENGGANTI SELURUH data saat ini dengan isi file backup. Download backup kondisi sekarang dulu bila masih diperlukan!
Format wajib: JSON berisi array accounts, orders, transactions — persis seperti hasil Download Backup. Array murni [...] juga diterima dan diimpor sebagai daftar orders. Maks 8 MB.
Struktur Database JSON Array
{
  "settings": { ... },
  "accounts":     [ {kode, nama, tipe, saldo_normal, is_cash}, ... ],
  "orders":       [ {queue_no, client_name, wa_number, judul,
                     script_teks, harga, dp, status, ...}, ... ],
  "transactions": [ {tanggal, keterangan, akun_debit,
                     akun_kredit, jumlah, order_id}, ... ]
}
